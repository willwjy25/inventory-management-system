# Inventory Management System

A modern full-stack Inventory Management System built using Next.js, Express.js, PostgreSQL, Prisma ORM, and TypeScript.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- Express.js
- TypeScript
- Prisma ORM

### Database
- PostgreSQL

## Features

- Authentication
- Dashboard
- Product Management
- Category Management
- Supplier Management
- Stock In
- Stock Out
- Transaction History
- Reports
- Responsive UI
